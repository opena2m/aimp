# AIMP 04 — 安全与成本管理

**状态:** 草案 · **版本:** 1.0.0-draft · **规范性**

物理动作是不可逆的。提示词注入、模型幻觉、简单失误一旦触及物质世界，就会变成昂贵、破坏性、
甚至危险的事件。本章规定 AIMP 网关 **必须** 强制实施的最小安全与成本控制。

## 1. 威胁模型

AIMP 网关需要防御：

| # | 威胁 | 缓解措施 |
|---|---|---|
| T1 | Agent 失控（幻觉循环、无限打印） | 预算上限、速率限制、询价-锁定生命周期 |
| T2 | 通过素材或遥测注入提示词 | 素材哈希、沙箱化审核视觉、脱敏工具 Schema |
| T3 | 被入侵的适配器伪造"成功" | 网关侧校验遥测、必要传感器读数、签名 webhook |
| T4 | 客户端凭据泄露 | 短期 Token、按设备限 Scope、异常检测 |
| T5 | 物理危害（火灾、伤人、化学泄漏） | 风险等级、HITL 闸门、中止优先 |
| T6 | 遥测媒体造成隐私泄露 | 短期预签名 URL、按租户分区存储 |

## 2. 认证

- 客户端 **必须** 对每次调用进行认证。未认证请求 **必须** 返回 HTTP 401，且响应体
  **不得** 泄露任何信息。
- **推荐** 使用 OAuth 2.1：
  - 短期 Access Token（≤ 1 小时）；
  - Refresh Token 与设备指纹绑定；
  - 按 Scope 划分 Token（如 `aimp:quote`、
    `aimp:execute:manufacturing.print.2d.v1`）。
- 网关与适配器之间 **推荐** 使用双向 TLS（mTLS）。
- Webhook **必须** 进行 HMAC 签名（§01.7）。

## 3. 授权模型

### 3.1 主体

AIMP 区分三类主体，审计日志 **必须** 能将三者区分：

- **agent** —— 自主 AI 主体（`agent://org/agent-name`）。
- **human** —— 稳定 user ID 标识的自然人主体。
- **system** —— 网关自身或受信任的自动化策略。

**approval_token**（§03.3.3）把三者连接起来：`agent` 发起请求，`human` 签发授权，
`system` 执行强制。

### 3.2 策略评估

对每一次 `execute` 调用，网关 **必须** 按顺序评估：

1. **Token 有效性** —— 签名、有效期、Scope。
2. **领域白名单** —— 本 Token 是否有权调用此 `domain`？
3. **设备白名单** —— 本 Token 是否有权操作此 `device_id`？
4. **预算校验** —— 报价金额是否在剩余预算之内？
5. **风险等级策略** —— 本领域是否需要人工批准？
6. **速率限制** —— 是否超出 Token 的调用频率上限？

任何一项失败 **必须** 用具体错误码（§06）中止调用，并写入审计日志。

## 4. 风险等级

每个领域 Schema 声明自己的风险等级。网关 **可以** 向上覆盖（更严格），**不得** 向下覆盖。

| 等级 | 示例 | 默认策略 |
|---|---|---|
| **routine（常规）** | 二维打印、标签打印、简单温控 | 仅需 Agent 批准；仅强制预算上限。 |
| **restricted（受限）** | 易燃耗材 3D 打印、CNC、面向人类食用的烹饪 | 金额超过门槛（默认等值 50 USD）时 **必须** 人工确认；或对未经审核的新素材 **必须** 人工确认。 |
| **hazardous（危险）** | 高功率激光、化学反应釜、生物操作、涉及邻近人体的运动 | 每一次 `execute` **必须** 人工确认。中止除 `/abort` 外，**必须** 支持一键物理急停按钮。 |

网关 **应当** 在 `discover` 中暴露风险等级，让客户端在规划开销之前就能评估策略。

## 5. 成本生命周期

每一次物理动作都要流经五个会计状态。网关 **必须** 为每个主体维护一份 **账本**，逐项记录。

```
estimate ──▶ quote ──▶ reserve ──▶ commit ──▶ settle
                                     │
                                     └──▶ partial_refund（中止时）
```

### 5.1 Quote（询价）

网关签发带有 `valid_until` 的价格。在有效期内，除非素材被撤销或内容审查失败，网关
**必须** 兑现报价。

### 5.2 Reserve（锁定）

在 `execute` 时，网关锁定：

- 货币金额（预授权支付工具，或扣减内部预算）；
- 耗材（虚拟扣减库存）；
- 机器时间槽（拒绝重叠预约）。

若未在合理时限内进入 `EXECUTING`（**推荐** 5 分钟），锁定 **必须** 过期释放。

### 5.3 Commit（承诺）

执行开始后，锁定转为承诺。耗材已进入实质性消耗。

### 5.4 Settle（结算）

进入 `COMPLETED` 时，网关记录最终成本。由于实际计量的细微差异（稍多耗材、稍长时间），
最终值 **可以** 与报价略有不同。但 **不得** 超出报价金额加上声明的容差（**推荐** 10%）。
超出容差部分由网关吸收。

### 5.5 中止的部分退款

进入 `ABORTED` 时，网关按已完成的执行比例加上固定准备成本计算 `final_cost`，在中止响应
中返回（§01.6.5）。

## 6. 预算强制

每个 Token 携带 **预算上下文**：

```json
{
  "budget": {
    "currency": "USD",
    "period": "daily",
    "ceiling": 200.00,
    "consumed": 37.40,
    "resets_at": "2026-04-25T00:00:00Z"
  }
}
```

网关 **必须**：

- 拒绝会使 `consumed` 超过 `ceiling` 的 `execute` 调用；
- 暴露 `GET /v1/budget` 供 Agent 自省查看剩余额度；
- 消耗达 80% 时推送 `budget_warning`，达 100% 时推送 `budget_exhausted` 事件。

## 7. Human-in-the-Loop（HITL）

在 AIMP 中，HITL 不是"可选特性"，它是一个 **协议状态**。

当策略要求人工介入时，网关进入 `AUDITING` 状态，并填充 `human_action_required`：

```json
{
  "human_action_required": {
    "reason": "policy.risk_tier.hazardous",
    "approval_url": "https://approval.example.com/review/01J8...",
    "expires_at": "2026-04-24T06:30:00Z",
    "fallback_action": "ABORT"
  }
}
```

人工审核者查看素材、报价、已有审计媒体，签发 Approval Token。Agent 通过 `POST
/v1/jobs/{id}/resume` 提交 Token 恢复任务。若窗口过期，网关执行 `fallback_action`。

网关 **应当** 集成常见的审批渠道：带一次性链接的邮件、飞书 / 钉钉 / Slack 交互消息、
内部审批门户。网关 **必须** 能验证批准签名；仅有"按钮被点击"是不够的。

## 8. 素材完整性

- `quote` 或 `execute` 中引用的每份数字素材 **必须** 携带 `hash_sha256` 或等价的内容哈希。
- 适配器下载完成后 **必须** 校验哈希。失败视为硬错误（`ERR_ASSET_HASH_MISMATCH`）。
- 对客户端提供的素材 URL，条件允许时 **应当** 由网关代为抓取，避免适配器侧 SSRF。

## 9. 中止优先

中止是安全基元：

- **必须** 接受任何持有 `aimp:abort` Scope 的已认证主体发起的调用；
- **不得** 限流；
- **不得** 要求有效的 `approval_token`；
- **必须** 获得适配器确认后才能返回成功；
- 对危险等级设备，**应当** 与物理急停机构（按钮/拉线）联动。

若在合理时间内（**推荐** 3 秒）未能收到适配器确认，网关 **必须** 升级：将任务置为
`FAILED`，推送 Pager 级别告警。

## 10. 日志与审计

网关 **必须** 维护一份追加式审计日志。每条记录至少包含：

- 单调递增序号
- UTC 时间戳
- 主体（agent / human / system）
- 动作（方法、状态变更、策略决策）
- 相关 ID（`job_id`、`quote_id`、`device_id`）
- 用于完整性链的字段（如前序记录的滚动哈希）

日志保留期至少应符合运营所在司法辖区的法规最低要求（**推荐** 至少 1 年）。日志
**必须** 可通过 `GET /v1/audit` 供合格主体查询。

## 11. 隐私

- 遥测媒体（摄像头画面）经常会含有隐私内容（比如路过车间的路人）。网关 **必须**：
  - 分租户隔离存储；
  - 按需进行打码 / 裁剪 / 替换；
  - 在法定时限内处理删除请求。
- `logistics` 中的收件人信息属于 PII。网关 **必须** 静态加密存储，且 **不得** 通过
  `GET /v1/audit` 向无权主体披露。
