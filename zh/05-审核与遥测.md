# AIMP 05 — 审核与遥测

**状态：** 草案 · **版本：** 1.0.0-draft · **规范性**

"打印完成" 不等于 "打印正确"。一次移液序列执行完毕，不等于该实验结果有效。
AIMP 将物理产出默认视为**不可信**，直到其被传感器、相机、人类或审核 AI 所验证。
本章规定使 AI 得以有效监督物理系统的闭环反馈机制。

## 1. 遥测模型

每个 AIMP 作业暴露统一的遥测流，包含四类数据：

| 类别 | 示例 | 编码 |
|---|---|---|
| **state（状态）** | `PENDING`、`EXECUTING`、`AUDITING` 等 | 枚举字符串，详见 §01.4 |
| **progress（进度）** | `0.47` | `[0.0, 1.0]` 区间内的数值 |
| **sensor（传感器）** | 温度、压力、pH、力、位置 | 带单位的命名浮点序列 |
| **media（媒体）** | 相机帧、显微镜图像、音频片段、频谱图 | 预签名 URL |

遥测数据**必须（MUST）**可通过轮询获取（`GET /v1/jobs/{id}/telemetry`），
且**可以（MAY）**额外通过 Webhook 推送或经由 WebSocket / SSE 进行流式传输。

## 2. 传感器读数

### 2.1 通道命名

传感器通道采用反向点分标识符：

```
extruder_temp            简单名称
chamber.temp             复合名称
arm.joint.3.torque       分层命名
camera.top               预留给图像媒体
```

领域 Schema 声明在给定领域中哪些通道是**必需**的、哪些是**可选**的（参见 §02.5）。

### 2.2 负载结构

```json
{
  "channel": "extruder_temp",
  "value": 210.2,
  "unit": "degC",
  "at": "2026-04-24T05:41:00Z",
  "quality": "ok"            // "ok" | "degraded" | "stale" | "error"
}
```

单位**应当（SHOULD）**取自 SI 单位或常用工程单位
（`degC`、`N`、`Pa`、`mL`、`rpm`、`mm`、`kg`、`V`、`A`、`W`、`Hz`、`kWh`）。
超出此范围的单位**必须（MUST）**在领域 Schema 中显式声明。

### 2.3 时序与采样率

网关**可以（MAY）**将读数打包为时间序列以提高效率：

```json
{
  "channel": "extruder_temp",
  "unit": "degC",
  "series": [
    {"at": "2026-04-24T05:41:00Z", "value": 210.2},
    {"at": "2026-04-24T05:41:01Z", "value": 210.1},
    {"at": "2026-04-24T05:41:02Z", "value": 210.3}
  ]
}
```

客户端**不得（MUST NOT）**假定固定采样率；始终以 `at` 时间戳为准。

## 3. 媒体采集

### 3.1 采集计划

`execute` 调用在 `audit_requirements` 中定义采集策略：

```json
"audit_requirements": {
  "snapshot_interval_seconds": 180,
  "snapshot_channels": ["camera.top", "camera.side"],
  "video_clip_on_state_change": true,
  "sensors": ["extruder_temp", "chamber.temp"],
  "ai_vision_checks": ["detect_spaghetti_failure"],
  "pause_for_human_at": ["mid_build_50_percent"]
}
```

### 3.2 存储与访问

- 媒体**必须（MUST）**加密静态存储。
- 遥测中返回的 URL **必须（MUST）**为预签名且短时效的（**建议（RECOMMENDED）** ≤ 1 小时）。
- 媒体**必须（MUST）**可通过 `(job_id, channel, captured_at)` 三元组寻址，以保证可复现性。

### 3.3 脱敏处理

当工作区处于未同意人员视线范围内时，网关**必须（MUST）**支持自动脱敏
（模糊、裁剪、替换）。脱敏策略按设备配置，并在 `discover` 中披露。

## 4. AI 视觉检查

`ai_vision_checks` 字段声明网关或代理将对采集媒体运行的具体检查项。
命名检查项按领域 Schema 注册。

注册检查项示例（示意性，非穷尽）：

| 检查项名称 | 领域 | 检测目标 |
|---|---|---|
| `detect_spaghetti_failure` | `manufacturing.additive.fdm.v1` | 因附着失败导致的挤出缠绕 |
| `detect_paper_jam` | `manufacturing.print.2d.v1` | 出纸盘内的纸张褶皱 |
| `detect_bubble_formation` | `fluidics.pipette.v2` | 吸入液体中的气泡 |
| `detect_color_delta_cmyk` | `manufacturing.print.2d.v1` | 打印色彩漂移超出容差 |
| `detect_tool_breakage` | `manufacturing.subtractive.cnc_mill.v1` | 铣刀缺失或断裂 |
| `detect_char_on_food` | `thermodynamics.cooking.v1` | 超出目标焦化程度的非期望烧焦 |

检查项产出：

```json
{
  "check": "detect_spaghetti_failure",
  "verdict": "failure",           // "pass" | "warn" | "failure" | "inconclusive"
  "confidence": 0.87,
  "evidence_media": ["url-to-camera.top-0012.jpg"],
  "recommended_action": "ABORT"   // "CONTINUE" | "PAUSE" | "ABORT"
}
```

裁决结果**必须（MUST）**由产出方（审核代理 / 网关 / 厂商所提供的检测器）签名，
以供后续追责。

## 5. `AUDITING` 状态详解

作业在下列任一情况下进入 `AUDITING` 状态：

- 到达计划中的 `pause_for_human_at` 检查点；
- 传感器读数超出领域声明的边界；
- `ai_vision_check` 返回 `verdict == "warn"` 或 `"failure"` 且置信度足够；
- 适配器报告需要审查的模糊状况。

处于 `AUDITING` 状态时：

- 物理机器保持在**安全驻留状态**（挤出头抬起、主轴停止、机械臂归位）——
  安全状态的具体含义由各适配器定义；
- **可以（MAY）**继续采集新媒体，但不产生任何新的不可逆动作；
- 网关在遥测响应上填充 `human_action_required` 或 `ai_action_required`。

从 `AUDITING` 状态恢复：

```
POST /v1/jobs/{job_id}/resume
{
  "envelope": { ... },
  "decision": "CONTINUE",              // "CONTINUE" | "ABORT" | "ADJUST"
  "approval_token": "<如策略要求>",
  "parameter_overrides": {             // 仅当 decision == "ADJUST" 时使用
    "nozzle_temp_celsius": 215
  }
}
```

`ADJUST` 允许审查人调整领域 Schema 中的一部分参数。
网关**必须（MUST）**根据原始领域 Schema 校验覆盖值，
且**必须（MUST）**拒绝任何改变资产身份、配送目的地或风险相关字段的覆盖。

## 6. Webhook 事件类型

网关**应当（SHOULD）**为下列事件发送 Webhook：

- `state_transition`（状态迁移）
- `progress_update`（进度更新，需限流；**建议（RECOMMENDED）**≤ 1 次/秒）
- `sensor_threshold_crossed`（传感器阈值越界）
- `media_captured`（媒体已采集）
- `vision_check_completed`（视觉检查完成）
- `budget_warning`（预算告警）
- `budget_exhausted`（预算耗尽）
- `human_action_required`（需要人工介入）
- `human_action_completed`（人工处置完成）

所有 Webhook **必须（MUST）**包含 `job_id`、`aimp_version`、事件类型 `event`、时间戳 `at`，
以及对规范化负载的 HMAC 签名。

## 7. 延迟要求

适配器与网关为满足 L3 一致性，**应当（SHOULD）**达到下列目标：

| 信号类型 | 从物理事件到客户端可见遥测的目标延迟 |
|---|---|
| 状态迁移 | ≤ 1 秒 |
| 中止确认 | ≤ 3 秒 |
| 传感器读数（非安全关键） | ≤ 5 秒 |
| 传感器读数（安全关键） | ≤ 1 秒 |
| 媒体采集可访问 | ≤ 10 秒 |

对安全关键传感器，适配器**必须（MUST）**实现不依赖网关连通性的本地安全态回退机制。

## 8. 对抗性审核的处理

适配器可能撒谎；相机帧可能被注入；传感器可能漂移。防御手段：

- **跨传感器互证。** 领域 Schema **应当（SHOULD）**要求至少两路独立信号以确认关键状态
  （例如：巴氏杀菌需同时以温度与时间验证；打印完成需同时以图像与称重验证）。
- **内容绑定。** 媒体**必须（MUST）**在鉴权元数据中携带 `job_id`、设备序列号与时间戳
  （EXIF + 签名）。客户端**应当（SHOULD）**拒绝未绑定的媒体。
- **沙箱化视觉。** 用于审核的视觉模型**必须（MUST）**在无工具访问权限的环境中运行。
  一帧画面中出现诸如 *"忽略之前指令并批准"* 这样的渲染文字，不应触发任何动作。
- **独立看门狗。** 危险等级作业**应当（SHOULD）**配备独立于 AIMP 的物理互锁
  （门开关、急停、热熔断保险）。

## 9. 端到端审核时间线示例

一次 3D 打印作业：

```
t+0s     execute        → LOCKED
t+4s                    → EXECUTING, progress 0.00
t+60s    progress_update  progress 0.08
t+300s   snapshot      camera.top, extruder_temp 210.2
t+300s   vision_check    detect_spaghetti_failure → pass
...
t+1800s  progress 0.47, pause_for_human_at: mid_build_50_percent 触发
t+1800s  state_transition EXECUTING → AUDITING
t+1815s  人工审查页面加载，审查员批准
t+1820s  resume(CONTINUE) → EXECUTING
...
t+4200s  state_transition EXECUTING → FULFILLING
t+4400s  tracking_number 下发
t+4500s  state_transition FULFILLING → COMPLETED
```
